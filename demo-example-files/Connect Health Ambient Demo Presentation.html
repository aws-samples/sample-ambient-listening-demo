AWS Console Walkthrough

What's deployed — a quick tour of the infrastructure

Amazon ECS
• Fargate cluster & service
• Task definition: 1 vCPU, 2GB RAM
• Container port 3000 (Next.js)
• Auto-scaling & health checks
Amazon S3 + KMS
• Output bucket (clinical notes)
• SSE-KMS encryption enabled
• Block all public access ✓
• Versioning + access logging
Amazon Connect Health
• Domain configuration
• Subscription + note template
• S3 output path mapping
• Service principal permissions
ALB + WAF
• HTTPS listener (TLS 1.2+)
• Target group → ECS tasks
• WAF rate limiting rules
• ACM wildcard certificate
Secrets Manager
• FHIR OAuth2 credentials
• DB connection secret
• OpenEMR admin creds
• 30-day auto-rotation
VPC + Security
• 2-AZ private subnets
• Security groups (ALB → ECS only)
• VPC Flow Logs → CloudWatch
• cdk-nag HIPAA validated
